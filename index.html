☁️ Backup su GitHub

Backup completo su una tua repo GitHub privata: archivio salite (con sezioni e correzioni DEM), registro ascensioni, sessioni, tracce GPX, zone e pesi. Ogni backup è una versione datata: le versioni precedenti restano nella cronologia della repo, recuperabili dalla pagina del file su GitHub.

Backup mai eseguito

Come creare il token: github.com → Settings → Developer settings → Fine-grained tokens → Generate new token → Repository access: solo la repo del backup → Permissions → Contents: Read and write. Il token resta solo su questo telefono e non viene mai scritto nel file di backup. Nel campo «Scadenza token» inserisci la data di scadenza che vedi nella lista dei token: l'app ti avvisa in anticipo quando sta per scadere.
